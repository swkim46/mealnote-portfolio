# 소규모 식단 관리 앱 개발안 v1.2

2026-10-20 · 직접 개발(Codex·Claude Code) · 트레이너 5명 이하, 소수 회원 · 링크로 전달하는 모바일 웹앱(PWA)

## v1.1에서 바뀐 것

| 항목 | v1.1 | v1.2 |
|---|---|---|
| 앱 형태 | React Native + Expo, 스토어 배포 | **React + Vite 모바일 웹앱(PWA)**, 링크로 전달, 홈 화면에 추가해 사용 |
| 로그인 | 이메일 로그인 | **닉네임 + 숫자 6자리 PIN**. 이메일·전화번호 등 개인정보를 받지 않음 |
| 첫 화면 | 정하지 않음 | **회원 / 트레이너 선택** 후 가입 또는 로그인 |
| 담당 연결 | 운영자가 Supabase 관리 화면에서 배정 | **트레이너가 먼저 가입**하고, 회원이 가입할 때 트레이너 목록에서 선택 |
| 트레이너 가입 제한 | 운영자 설정 | 운영자가 나눠 주는 **트레이너 등록 코드** 입력 |
| 알림 | Expo Push | **v1은 앱 안 배지만**(미확인 건수·새 피드백 표시). 웹 푸시는 v2 |
| 메일 발송·도메인 | Resend, 도메인 구매 | **필요 없음** |
| 호스팅 | 앱스토어 | **Cloudflare Pages 무료** |
| 월 비용 | 0원부터 | **0원** |

## 화면

| 회원 | 트레이너 |
|---|---|
| 오늘: 오늘 기록한 끼니, 식단 기록하기 | 확인 목록: 미확인 / 답변 대기 / 전체 |
| 기록: 날짜별 식사 | 담당 회원: 회원별 식사 기록 |
| 피드백: 트레이너 답변 모음, 새 답변 표시 | 식사 상세: 확인 완료 표시, 피드백 댓글 |
| 식사 상세: 사진·먹은 시각·설명, 추가 질문 | |

식사 등록 항목은 사진(선택), 먹은 날짜·시각, 끼니 구분, 음식 설명, 트레이너에게 한마디(선택)입니다. 먹은 시각과 등록 시각은 따로 저장합니다. 사진은 올리기 전에 휴대폰에서 긴 변 800px로 줄입니다.

## 데이터와 권한

| 테이블 | 내용 |
|---|---|
| profiles | 닉네임, 회원·트레이너 구분 |
| assignments | 회원과 담당 트레이너 연결(회원 1명당 트레이너 1명) |
| meals | 회원, 먹은 날짜·시각, 끼니, 음식 설명, 메모, 사진 경로, 등록 시각, 확인 시각, 회원이 마지막으로 본 시각 |
| comments | 식사, 작성자, 내용, 작성 시각 |
| app_settings | 트레이너 등록 코드(암호화한 값). 앱에서 읽을 수 없음 |

회원은 자기 기록만, 트레이너는 담당 회원 기록만 볼 수 있도록 DB와 사진 저장소에 권한 규칙을 겁니다. 사진은 비공개 저장소에 두고 1시간짜리 임시 주소로 보여 줍니다.

## 인프라와 비용

| 필요한 것 | 선택 | 월 비용 |
|---|---|---|
| 로그인·DB·사진 저장 | Supabase Free, 서울 리전 | 0원 |
| 웹앱 호스팅 | Cloudflare Pages Free, `*.pages.dev` 주소 | 0원 |
| 도메인 | 쓰지 않음 | 0원 |
| **합계** | | **0원** |

**Supabase Free에서 먼저 찰 것은 사진 저장 1GB입니다.** 사진 1장 150KB, 하루 3끼, 30일 기준으로 회원 1명이 월 약 13.5MB를 씁니다. 회원 10명이면 월 약 135MB라 약 7개월 뒤 1GB에 닿습니다. 그때 Supabase Pro(월 USD 25, 예산 환산 1,500원/USD 적용 시 약 3만 7,500원)로 올리거나 오래된 사진을 정리합니다. 사진 1장 크기는 와이어프레임의 압축 설정에서 나온 계획 가정입니다.

Supabase Free 프로젝트는 일주일간 요청이 없으면 일시 정지됩니다. 실제 사용 중에는 해당하지 않지만 개발 공백기에는 대시보드에서 다시 켜야 합니다.

Cloudflare Pages Free는 계정당 프로젝트 100개, 월 빌드 500회, 파일 2만 개까지이며 대역폭 상한은 공식 한도 문서에 적혀 있지 않습니다.

## 개발 순서

| 단계 | 내용 |
|---|---|
| 1 | React 앱 골격, 와이어프레임 디자인 이식, 홈 화면 설치(PWA) |
| 2 | Supabase 테이블·권한 규칙·사진 저장소·가입 처리 |
| 3 | 회원/트레이너 선택, 가입·로그인, 역할별 화면 |
| 4 | 회원 화면: 식사 등록·사진 업로드, 기록, 피드백, 추가 질문 |
| 5 | 트레이너 화면: 확인 목록, 담당 회원, 확인 완료, 피드백 |
| 6 | Cloudflare Pages 배포, 실제 휴대폰 점검 |

## 운영 기준(기본값)

| 질문 | v1 기준 |
|---|---|
| PIN을 잊으면 | 운영자가 Supabase 관리 화면에서 재설정 |
| 같은 닉네임 | 가입 불가 |
| 회원의 식사 수정·삭제 | 본인 기록은 언제든 가능 |
| 트레이너 간 열람 | 담당 회원만 |
| 사진 보관 | 기한 없음. 1GB에 가까워지면 정리 방식 결정 |

v2 후보는 웹 푸시, 회원의 담당 트레이너 변경, 트레이너의 PIN 재설정, 사진 보관 기한, 체중·목표 기록입니다. 칼로리 자동 분석·결제·센터 관리자 웹은 넣지 않습니다.
