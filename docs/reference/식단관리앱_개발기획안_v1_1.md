# 소규모 식단 관리 앱 개발안

2026-10-20 · 직접 개발, Codex·Claude Code 활용, 트레이너 5명 이하와 소수 회원 기준

## 만들 것

**회원과 트레이너가 같은 앱을 사용하고, 로그인한 계정에 따라 화면만 다르게 보여 줍니다.** 회원이 식사 시각·음식 설명·사진을 올리면 담당 트레이너가 확인하고 댓글로 피드백합니다.

| 회원 화면 | 트레이너 화면 |
|---|---|
| 식사 등록: 실제 먹은 시각, 음식 설명, 사진 | 담당 회원들의 새 식사 목록 |
| 내 식사 기록 | 회원별 식사 기록 |
| 피드백 확인·추가 댓글 | 식사 사진·설명 확인, 댓글 작성, 확인 완료 표시 |

식사 시각은 기본값을 현재로 두고 수정할 수 있게 합니다. 업로드 시각과 식사 시각은 따로 저장합니다. 트레이너는 미확인 식사를 먼저 보고, 식사별 댓글에서 회원과 대화합니다.

## 사용할 기술과 비용

| 필요한 것 | 선택 | 초기 비용 |
|---|---|---|
| iPhone·Android 앱 | React Native + Expo | 프레임워크 무료 |
| 로그인·DB·사진 저장·API | Supabase | 무료 플랜부터 시작 |
| 새 식사·댓글 푸시 | Expo Push | 발송 무료 |
| 앱 빌드 | EAS Build | 무료 월 제공량 내 사용 |
| 가입 확인·비밀번호 재설정 메일 | 이메일 로그인 사용 시 Resend를 SMTP로 연결 | 무료 월 3,000통·하루 100통 이내 |
| 메일 발송 도메인 | 보유 도메인 사용 또는 신규 구매 | 신규라면 연 2만~3만원을 계획 예산으로 가정. 실제 구매가 확인 필요 |

**별도 서버·관리자 웹을 만들지 않고 Supabase에서 필요한 기능을 처리합니다.** 초기 트레이너 계정·담당 회원 배정은 Supabase 관리 화면에서 직접 설정해도 됩니다. 앱에서 회원이 스스로 트레이너 권한을 얻지는 못하게 합니다.

무료 플랜의 핵심 제약은 **사진 저장 총량 1GB와 월 일반 전송량 5GB**입니다. 사진을 약 300KB로 압축한다는 가정에서 회원 10명이 하루 3장씩 30일 올리면 월 약 270MB, 30명이면 약 810MB가 쌓입니다. 보관 사진은 누적되므로 사용량을 보고 유료로 전환합니다. 이는 썸네일·별도 복사본을 제외한 계획 계산입니다.

Supabase Pro는 **월 USD 25부터**, 예산 환산 USD 1 = 1,500원 적용 시 **약 3만 7,500원**입니다. 사진 100GB 등이 포함됩니다. 초기에는 운영 프로젝트 하나만 사용하고 개발은 로컬 환경에서 진행하면 됩니다. 추가 프로젝트·초과 사용량은 별도입니다.

따라서 소수 인원 테스트는 **월 서비스 요금 0원부터**, 사진 저장량 때문에 Pro로 전환하면 **기본 월 약 3.8만원부터**로 생각하면 됩니다. Codex·Claude Code 구독료와 앱스토어 계정비는 별도이며, 기존 구독을 사용하면 해당 구독 외의 앱 내 AI API 비용은 필요하지 않습니다.

## 최소 DB

| 테이블 | 내용 |
|---|---|
| profiles | 계정, 회원·트레이너 구분 |
| assignments | 담당 트레이너와 회원 연결 |
| meals | 회원, 실제 식사 시각, 등록 시각, 음식 설명, 사진 경로, 확인 시각 |
| comments | 식사 ID, 작성자, 댓글 내용, 작성 시각 |

사진은 비공개 저장소에 보관합니다. 회원은 자기 기록만, 트레이너는 담당 회원 기록만 볼 수 있도록 DB와 사진 접근 권한을 설정합니다.

## 개발 순서

1. 로그인과 회원·트레이너 연결을 만듭니다.
2. 회원의 사진·식사 시각·음식 등록과 내 기록 목록을 만듭니다.
3. 트레이너의 담당 회원 목록·미확인 식사·확인 완료를 만듭니다.
4. 식사별 댓글을 연결해 피드백과 추가 질문을 주고받게 합니다.
5. 실제 소수 회원과 사용한 뒤 새 식사·댓글 푸시를 붙입니다.

처음에는 이 흐름이 끝까지 작동하는 데 집중합니다. 칼로리 자동 분석·결제·별도 채팅방·센터 관리자 웹은 초기 범위에 넣지 않습니다.

## 비용 근거와 범위

공식 요금·조건은 2026-10-20 확인 기준입니다. 환산율·사진 크기·도메인 예산은 자체 계획 가정입니다. 무료 빌드·메일 한도와 사진 보관량을 넘으면 추가 비용을 확인해야 합니다.

- [Supabase 요금](https://supabase.com/pricing): 무료 저장·전송 한도, Pro 기본료.
- [Expo 요금](https://expo.dev/pricing): 무료 빌드 월 제공량과 플랜.
- [Expo Push](https://docs.expo.dev/push-notifications/faq/): 푸시 발송 무료.
- [Resend 요금](https://resend.com/pricing): 무료 발송량.
- [Supabase SMTP](https://supabase.com/docs/guides/auth/auth-smtp): 운영용 이메일 발송 서비스 연결 필요.
- [Apple 개발자 가입](https://developer.apple.com/programs/enroll/), [Google Play 등록](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en): 계정 비용.

v1.0의 외주 인건비·대규모 운영 가정은 이 버전에 적용하지 않습니다.
